# SHOPEASYY INDIA - Bharat Ki Apni Dukan 

SHOPEasyy India is a modern and responsive frontend e-commerce web application inspired by Indian online shopping platforms. The project focuses on creating a localized shopping experience with multilingual support, interactive UI components, authentication functionality, and dynamic product rendering using Vanilla JavaScript.

## Features

### 🛒 E-Commerce Functionalities

* Product catalog with multiple categories
* Dynamic product cards
* Shopping cart system
* Add to cart functionality
* Product pricing and discounts
* Recently viewed products section

### 🌐 Multi-Language Support

* Support for multiple Indian languages
* Dynamic language switching
* Language selection modal
* Localized UI text rendering

### 🔐 Authentication System

* Login & Signup pages
* Form validation
* LocalStorage-based authentication
* Persistent login session
* User account handling

### 🎨 UI/UX Features

* Responsive design for all devices
* Hero image slider/carousel
* Animated sections and hover effects
* Modern Indian-themed UI
* Tricolor branding aesthetics
* Interactive navigation bar

### ⚡ Performance & Architecture

* Pure frontend implementation
* No external frameworks used
* Modular JavaScript structure
* Lightweight and fast loading
* Fully responsive layout

## Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript (ES6)
* LocalStorage API
